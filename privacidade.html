Política de Privacidade

Última atualização: 08/10/2026

1. Finalidade

O Rclone Pessoal é uma configuração OAuth utilizada exclusivamente pelo proprietário para acessar sua própria conta do Google Drive através do software Rclone no Ubuntu.

2. Acesso aos dados

O aplicativo solicita acesso ao Google Drive para visualizar, criar, modificar, organizar e excluir arquivos, conforme as operações realizadas pelo próprio usuário.

3. Armazenamento

As credenciais OAuth são armazenadas localmente na configuração do Rclone. O Rclone pode manter arquivos temporários em cache no computador para melhorar o desempenho do acesso aos arquivos.

4. Compartilhamento

Esta configuração pessoal não possui servidor próprio para receber arquivos ou credenciais, nem utiliza os dados para publicidade ou comercialização.

5. Revogação de acesso

O proprietário pode revogar a autorização OAuth nas configurações de segurança da sua Conta Google.

6. Contato

O contato é realizado pelo endereço de suporte informado na tela de consentimento OAuth do aplicativo.
